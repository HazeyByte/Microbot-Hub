# Plugin Patterns

## Plugin Design:
- Plugins should be modular and focused on a single functionality.
- Each plugin should have a clear interface and well-defined responsibilities.
- Plugins should interact with the game client through the Queryable API.

## State-machine Design:
- State-machine patterns are used to manage bot behavior.
- Each state in the state-machine represents a specific behavior or action.
- Transitions between states are triggered by events or conditions.
